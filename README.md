# aula-2--computa-o-em-nuvem
perguntas da aula 2
DESAFIO: VOCÊ É O ARQUITETO DE
NUVEM
Caso 1: Startup
Uma startup desenvolveu uma aplicação web.
A equipe possui poucos desenvolvedores e não quer perder tempo
administrando servidores ou sistemas operacionais.
Ela quer:
● desenvolver;
● publicar;
● atualizar a aplicação.
Qual modelo vocês escolheriam?
IaaS, PaaS ou SaaS?
Justifique.
R=O PaaS, permite que a equipe se concentre no desenvolvimento, publicação e atualização, sem precisar administrar servidores

Caso 2: Empresa com sistema legado
Uma empresa possui um sistema antigo que:
● depende de Linux;
● exige configurações específicas;
● precisa de controle sobre o sistema operacional;
● será migrado para a nuvem.
Qual modelo?
R= O IaaS, porque permite à empresa ter controle sobre o sistema operacional, podendo instalar Linux e realizar as configurações específicas necessárias para o sistema

Caso 3: Escritório
Uma pequena empresa precisa apenas:
● criar documentos;
● fazer apresentações;
● utilizar e-mail;
● compartilhar arquivos.
Ela não possui equipe de TI.
O que faz mais sentido?
R=O SaaS é o mais adequado porque a empresa precisa apenas usar ferramentas prontas, sem precisar instalar, configurar ou administrar servidores.

Caso 4: vocês decidem!
Uma universidade quer criar um novo sistema para que alunos
consultem:
● notas;
● faltas;
● horários;
● disciplinas.
A universidade possui uma equipe de desenvolvimento, mas não
quer administrar servidores.
Qual modelo vocês escolheriam?
R=O PaaS é o mais adequado porque a universidade possui uma equipe de desenvolvimento, mas não quer administrar servidores.
